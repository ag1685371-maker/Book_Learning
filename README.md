# Bo Shares the Berries

An illustrated children's picture book about sharing, starring Bo the bear cub, Dot the duckling and Lulu the lamb.

- `index.html` — the whole book in one page: cover, 5 illustrated pages, page-turning controls, and an **Ask the Book** panel that answers questions about the story with page citations.
- `data/chunks.json` — the story passages (narration, dialogue, scenes, character notes, moral) used by Ask the Book's search.

Open `index.html` in a browser to read it. Ask the Book's Claude-written answers only work when the page is hosted as a Claude artifact; elsewhere it shows the closest matching passage from the book.
